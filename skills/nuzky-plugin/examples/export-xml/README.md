# Export XML

Saves the timeline as Final Cut Pro 7 XML (xmeml 4), which Premiere Pro and DaVinci Resolve import. **Export XML**
asks where to save it. Every video, picture and sound clip goes onto a track of its own kind at its place in the
timeline, cut from the same part of its file. Texts, captions, effects and speed changes stay in Nuzky; the message
after the export says how many it left out.

It has full access, because it writes the file you choose. It changes nothing in the project.
